# workspace/

This is the **only folder the course's Python agents may read and write**. Think of it as their desk: the sandbox.

- Files agents create (reports, notes, drafts) appear here.
- `team_notes.md` is the shared notebook agents use to pass results to each other.
- Put input files for agents here too (e.g. `inbox/`, `policies/`).
- Sub-folders you'll see: `reports/`, `missions/`, `evals/`, `prompts/`, `cli_runs/`, `teams/`.

Everything in this folder except this README is ignored by git, so practice files never end up on GitHub. Delete anything here whenever you like.
